# 像素维修站 · Pixel Repair Lab

用鼠标指令卡或 Python 帮机器人完成任务。首页学习路线图汇总七门课程，进入模块后，任务列表会显示该模块的讲解、演示和练习。

七条课程路线共用一间 3D 维修站，各有自己的工位。进入 Python 课程，可以在补电机上选一块电池，看读数槽把电量送给程序，再看电量屏显示结果。进入数字电路或计算机视觉课程，会看到面包板或检测相机。终端、表格和仪表都可以直接操作，学习进度和练习记录单独显示。手机上各面板上下排列，浏览器无法显示实时 3D 时会使用同一工位的静态场景，仍然可以完成练习。

模块开头的桌面可以自由试验。点左侧换样品、点中间改设置，再点右侧设备运行。用鼠标也可以直接把样品拖到设备上。数据结构工位能对比队头和栈顶取件，数据库工位能换条件查看命中的行，视觉检测台能调阈值观察哪些框会留下。「复位」会恢复本次开场实验的初始设置。

在循环课上，单步执行会带动读数头和补电架，记录槽会在程序写入结果时收到数值。数据结构课可以直接点选架上的电池和插入位置。CPU 实验会点亮正在读写的内存线路，逻辑门的拨杆可以直接点按。NumPy 切片和掩码会在立体数组上抬起实际选中的元素，分组统计会按运行结果搭起柱形，像素取样台可以点选色块查看三个 RGB 分量。教具上的「俯视」按钮可以切换观察角度。

Python 课堂沿用同一批维修站电池。赋值台先算右边的式子，再把新电量写回指定的格子。数轴和安全门分别显示两个条件的判断结果，芽芽沿程序选中的分岔行动。在函数工作台上，可以同时看到主程序和函数各自的变量，跟到函数返回的那一步。模块工位把两个文件分开，调试工位则可以逐块比较实际输出和预期。写自己的函数时，切换用例就能看到换了哪些输入，运行后再看函数实际交回了什么。

数据结构与算法课程可以在电池架上取放、交换和查找，也可以点地图格查看搜索前沿。排序演示能停在两次写入之间，折半查找会留下下一轮要查的区间。运行算法示例或自己的函数时，点「单步执行」再选要观察的变量，就能在对应代码行检查真实的格位、变量值或地图坐标。回看上一步会还原那一步的状态。

计算机课程里的开关、输出灯和 CPU 都可以直接点。用开关拼一个二进制数，换一片逻辑门看看输出，再给 CPU 一次时钟脉冲。执行 `ADD` 时能看到运算器收到哪两个数，执行 `STORE` 时能对照那个内存地址写入前后的值。在棋盘上，芽芽会随 `scan()` 俯身扫描，随 `submit()` 伸手交付，棋盘同时显示这一步实际读到或提交的值。单步和回放都沿用同一份执行记录。

## 启动游戏

从源码运行时，先安装自带 npm 的 Node.js 22.12 或更新版本。脚本位于项目根目录。

| 系统 | 首次初始化，更新源码后也运行一次 | 平时启动 |
| --- | --- | --- |
| Windows | 双击 `Setup.cmd` | 双击 `Start.cmd` |
| macOS | 双击 `Setup.command` | 双击 `Start.command` |
| Linux | `sh ./setup.sh` | `sh ./start.sh` |

初始化会按锁文件安装依赖、构建游戏，并在缺少 `.env` 时从模板创建。启动脚本会打开默认浏览器，在启动窗口按 Ctrl+C 可停止服务。默认地址是 [本地游戏](http://127.0.0.1:5173)，可在 `.env` 中修改 `PORT`。学习进度保存在当前浏览器，固定使用同一地址和端口方便继续上次的游戏。

要启用数据分析、SQL 和视觉课程的本地 Python 实验，先准备 64 位 Python 3.11–3.13，确保能够创建带 pip 的虚拟环境。Debian 或 Ubuntu 使用系统 Python 时可能需要安装对应版本的 `python3-venv` 包。初始化时加 `--labs` 即可安装实验依赖和模型，例如 Windows 用 `.\Setup.cmd --labs`，macOS 和 Linux 用 `sh ./setup.sh --labs`。仅启动服务可在启动命令后加 `--no-open`。

如果复制源码后丢失了执行权限，macOS 可在项目目录用 `sh ./Setup.command` 初始化、用 `sh ./Start.command` 启动。给孩子分发可直接打开的 Mac 应用，见下方「Mac 上给孩子使用」。开发时可在初始化后用 `npm run dev` 启动热更新。开发和生产模式都会从 `levels/` 读取关卡。

在首页的维修车间和挑战机库，点地面能让芽芽走过去，拖动可以环顾四周。点芽芽可以和它打招呼，点工作台进入下一课，点充电舱进入挑战。场景旁也有对应的操作按钮。编程、数据、视觉和 AI 课程各有一座小工作台，点设备可以看芽芽操作。

网格任务和竞技场在立体车间中运行。用 **现场全景** 查看整张地图，用 **跟随芽芽** 近看行走和收取电池的动作。拖动场景可以转动镜头，点格子可以查看坐标、角色、物品和通道状态。可以随时缩放、复位或切到 2D。两种视图共用同一份对局进度。

写代码或摆指令卡时，**运行** 和 **单步执行** 在屏幕底部的固定工具条上。网格关可逐步看芽芽执行指令、进入自己写的函数、带回返回值。从容竞技也可以展开一个回合中的程序步骤。遇到 `if` 会显示这次判断的真假，`for` 会显示取到的值，`while` 会显示继续或结束。绿实线是芽芽最近移动的一格，灰虚线是更早走过的路，点 **显示路线** 可以切换。在算法练习中，先选一个用例，再单步对照这组输入经过的分支和调用的函数。点 **运行** 验证全部用例。

指令卡和代码中的黄色实线标记当前指令，蓝色虚线标记下一步实际会执行的指令。遇到分支时，虚线跟随这次选中的分支。循环连续执行同一条指令时，两种标记会出现在同一处。执行停在错误或最后一条指令时，虚线消失。

从首页进入 **挑战场**，可按玩法路线闯关，也可在 **自由选关** 中按难度和前序课程筛选。目前有 694 关，其中 391 关为高难，100 关为超难。在 **网格解谜** 里可以从「天桥还是地道」开始，自己选钥匙门或激光通道送件。「双潮渡口」要在两座桥的脉冲间隙搬箱，「三班轮换的光闸库」则要用同一份程序应对三班不同的房间布局。机器人对抗可用键盘或鼠标练习，运行 Python 完成目标即可通关。计算机视觉路线可以用鼠标调整图像处理参数、标注边界框并检查检测结果。

**推箱子** 路线共有 502 关，按 30 个入门、116 个进阶、256 个高难和 100 个超难关排列。入门从一推到位开始，进阶需要为其他箱子保留通道。高难关「香料称量室」有 6 只箱子，最少需要 42 推。超难仓库有时要把已到位的箱子推出去，等其他箱子通过后再推回来。最后的「地球深部观测站」要把 5 箱传感器送到上层货位，最少需要 97 推。在 **挑战场 → 自由选关** 中将类型选为 **推箱子**，再按难度直接进入任意一关。

可以点方向直接推箱、撤销一步，也可以用指令卡或 Python 规划路线。箱子就位时，对应货位会亮起。全部交付后，签收单上能看到总步数和实际推箱次数。棋盘上方的 **音效** 可以打开到位提示音和通关乐句。

在 **自由选关 → 渡口短挑战** 可以连玩三场，也能直接选其中一场。从「渡口一 · 赶船」开始，用鼠标排指令卡选路。第二场把桥上脉冲提前一拍，可以带着自己的通关程序重跑。第三场可以拖动两块电池和一面墙，再让芽芽和总捡最近电池的机器人同时出发，逐拍对照各自的路线。

在 **自由选关 → 激光短挑战**，第一场可以踩开关走近路，也可以绕行拿钥匙开门。第二场只转动一面镜子，能直接重跑第一场的通关程序。第三场可以移动、转动镜子，给芽芽排好路线，再在同一回合对照芽芽与最短路机器人的位置和光束。

30 个大地图挑战分布在 **网格解谜** 和 **机器人对抗** 两条路线。想试机关，可以进「雾钟渡口」，在脉冲北桥和需要踏板的南浮桥之间选路。想跑远征，可以进「极光双营地的无线电」，在上下翻转的两张图上把天线和电芯送到电台。想和对手抢时间，可以进「发条花车巡游」，在三辆花车换位置的途中收齐面具。

## 打包并带到 Mac 或 Linux

### Mac 上给孩子使用

发布者提供与目标 Mac 匹配的 `.dmg`。孩子双击打开，将芽芽图标拖入「应用程序」，再双击「像素维修站」。游戏会在默认浏览器打开。用程序坞图标可以重新打开游戏窗口，退出应用会关闭本机服务。孩子无需安装运行环境、使用终端或更改安全设置。macOS 首次打开从网上下载的应用时，可能会显示常规确认。

### 为 Mac 生成签名、公证的 DMG

已有发布工具包时，从下面第 2 步开始。

1. 在 Windows、macOS 或 Linux 的项目目录用 `npm ci` 安装依赖，然后执行以下命令。需要 Node 22.12+、Python 3.8+ 和 `tar`。首次打包联网下载并校验运行时和实验依赖，之后会复用缓存。

```sh
npm run package
```

2. 在 `release/` 中选择对应的 `*-ReleaseKit.tar.gz`。在「关于本机」里看到 Apple 芯片选 `macos-arm64`，Intel 处理器选 `macos-x64`。将它解压到一台装有 Xcode、可运行目标架构的发布 Mac 上。发布 Intel 版可用 Intel Mac，也可在装有 Rosetta 的 Apple 芯片 Mac 上操作。游戏支持 macOS 13 及以上版本。
3. 在发布 Mac 的钥匙串里准备有效的 **Developer ID Application** 证书及其配对私钥。新建证书请让 Apple Developer Program 团队的帐户持有人办理。准备启用双重认证的团队 Apple 账户、Team ID 和 App 专用密码。[Apple 证书说明](https://developer.apple.com/help/account/certificates/create-developer-id-certificates) · [Apple 公证凭据说明](https://developer.apple.com/documentation/security/customizing-the-notarization-workflow)
4. 在已解压的工具包目录打开终端。第一条命令是一次性设置，按提示输入公证凭据，保存在这台 Mac 的钥匙串。第二条命令中的名称替换为自己的证书名称。运行 `/bin/sh ./publish.sh --check` 可先检查发布环境。

```sh
xcrun notarytool store-credentials "PixelRepairLab-notary" --apple-id "YOUR_APPLE_ID" --team-id "YOUR_TEAM_ID"
export MAC_SIGN_IDENTITY='Developer ID Application: YOUR NAME (TEAMID)'
/bin/sh ./publish.sh
```

发布脚本组装应用及内置的 Node、Python、实验库和模型，签名后启动应用自检，再将应用和磁盘映像提交给 Apple。收到公证票据后会将票据装订到产物，挂载映像并检查其中的应用。全部通过后，从 `output/` 取出 `.dmg` 分发给孩子。每份安装包附有 SHA-256。公开发布时可设置稳定的反向域名 `MAC_BUNDLE_ID`。在线 AI 可在使用者的 `~/Library/Application Support/PixelRepairLab/.env` 中配置。浏览器按本机地址和端口保存学习进度与对局。

### Linux 便携包与打包选项

用 `npm run package -- --target linux` 生成两种 Linux 便携包。目标架构为 x86_64 时选 `linux-x64`，aarch64 时选 `linux-arm64`，完整解压到可写目录后运行 `./start.sh`。首次启动会用包内的 Python 和 wheel 准备实验。可用 `--no-open` 仅启动服务，按 Ctrl+C 关闭。支持内核 4.18+、glibc 2.28+ 和提供 `GLIBCXX_3.4.25` 的 libstdc++。在线 AI 的配置放在目标机器的 `.env` 中。

用 `--target all` 同时生成 Mac 发布工具包和 Linux 便携包，也可指定单个目标。Mac 的旧脚本式便携包可用 `--format portable` 显式生成。`--output` 和 `--cache` 分别指定输出目录和缓存目录。需要核对传输时，将压缩包和对应的 `.sha256` 放在一起，Mac 用 `shasum -a 256 -c 文件名.tar.gz.sha256`，Linux 用 `sha256sum -c 文件名.tar.gz.sha256`。

## 总学习路线图

首页推荐按 Python、数据结构与算法、计算机、数字电路、数据科学、计算机视觉、AI 协作的顺序学习。每门课会标出建议先学的模块、各阶段的进度和整体完成状态。点击阶段就能进入课程，也可以在 **自由选课** 中直接选模块。首页依次是学习路线图、自由选课和挑战场。

**继续学习** 优先回到上次打开的未完成主线课。已经完成时，会找同一门课剩下的活动，再按总路线推荐下一课。选做挑战可以随时打开或跳过，结课项目计入主线进度。

## 学习记录和错题本

做对预测或完成一个棋盘目标时，可以在操作处看到对勾和进度。首次学完一个知识点、模块、课程主线或一组短挑战，芽芽会亮出金色星章，并显示完成数量。重玩挑战仍会记录本次成绩。系统开启“减少动态效果”时，印章与结果以静态形式展示。

顶部的 **学习记录** 显示近期完成的活动和待复习的练习。**错题本** 按知识点归类，显示做错次数和订正状态。点 **看动画**、**看演示** 或 **重做练习** 可以直接进入对应的内容。综合挑战和结课项目会列出涉及的多个主题。

提交练习后判定失败的一次尝试会记入错题本。通过同一道练习后，它会标为 **已订正**，从首页的 **建议复习** 移出。练习记录保存在当前浏览器，包含关卡和判定结果，不保存输入的代码或提示词。看复习材料时，首页的 **继续学习** 仍会记住主线学习的位置。

## 学习和回放

- **Python** 有基础、进阶和高级，依次练习顺序、变量和表达式，分支与循环，以及函数和嵌套循环。
- **数据结构与算法** 有数据结构、算法初级、算法进阶和算法高级。内容涵盖索引、栈、队列、字典、线性查找、二分、广度优先搜索和动态规划。
- **计算机** 分计算机原理和计算机结构，分别认识二进制与逻辑门，以及内存、寄存器和 CPU 指令。
- **数字电路** 从二进制灯和二极管开始。在「面包板：接亮第一盏灯」中，从元件盒拖出按钮、电阻和 LED，也可以点选两只脚的插孔。接好跳线后先预测，再通电观察电流。可以翻转 LED 或拔出元件换孔，跳线留在原处。结课项目「面包板项目：接出呼叫灯」会沿用同一块板上的元件和板内跳线。换下电源后，把按钮接到 Arduino D2，让 D13 驱动外接灯，运行呼叫灯程序验证。两节课的搭建进度分别保存在当前浏览器。
  面包板上的万用表可用鼠标拖动表笔，也可以先点表笔再点孔。断电用通断档查连接，通电用直流电压档测红笔相对黑笔的电压。最后的选做维修单会交来一块不亮的呼叫灯。记下读数、判断故障并修理后，点「放回表笔并复测」能用同一对孔、相同的按钮状态对照读数。运行同一个程序验收按下点亮和松开熄灭后，维修记录会保存在当前浏览器中。回放的步骤清单可以只看测量、判断、改线、复测或试灯。点选一步就能看到当时的面包板和读数，「上一步」「下一步」和自动播放都跟随当前分类。在测量步骤点「对比修好后的复测」，可以并排查看相同条件下的两块面包板、接线改动及读数。返回时仍在原步骤，之前正在播放的会接着播放。切回「完整过程」可以接着看这一步前后发生了什么。旧记录可回看先前保存的快照。
- **数据科学** 串联 NumPy、Pandas、统计分析和数据库。**计算机视觉** 从 OpenCV 的像素处理学到 YOLOX 的目标检测。**AI 协作** 从写清请求学到逐项核对和多轮修正。

讲解页用可播放的图解展示每一步的变化，配合预测题检查理解。演示页运行独立示例，支持暂停、拖动进度和逐步查看。练习进度按关卡 ID 保存在浏览器，可随时返回复习。

每节课标题下方的步骤条列出同一知识点的全部课节，按 **学概念 → 看演示 → 动手练** 排列，标出当前位置和已完成的步骤，点任意一步即可跳转。通过一节课后，页面底部会出现 **本课已完成**，写明下一步是什么，点 **继续前进** 直接进入。左侧任务列表用颜色区分讲解、演示、练习和选做，并自动滚动到正在学的那一节。

上课和闯关时，点侧栏顶部的 **精简** 可以只保留目录、返回入口和前后切换按钮。点 **隐藏** 可以把整个工作区留给棋盘或代码。需要选课时点 **目录**，选好后面板会自动关闭。点 **固定** 可以让完整列表留在左侧。浏览器会记住桌面的选择。手机上点 **任务列表** 即可临时打开目录。

讲解页先展示可以操作或播放的场景。补电机逐格显示增加的电量，电池架上的箭头指向入栈、出队的位置，检测框的交叠处用斜纹标出。可以单步观察、回看，也可以展开当前步骤的说明或课程笔记。预测题的选项标有字母，选中后会标出对错。

在数据工作簿里，运行切片、筛选、清洗或 SQL 查询后，可以点输入行号，查看它去了输出的哪一行、哪些单元格发生了变化。遇到被删的重复编号，可以直接跳到留下的那条记录。AI 装箱台把工单和这轮实装的物品并排摆放，需要自己核对时，直接在货格上勾出差异。

进入 Python 进阶的 **条件分支** 后，沿着分岔图查看电量和安全门的判断怎样选中 `if` 或 `else`，并逐步看到芽芽执行的动作。最后换一组电量和门状态，先预测路线，再运行验证。

在 **for 遍历** 中，跟着一排电池逐块查看循环变量、补电计算和追加结果，直到列表用完。换一排电池后，先预测循环次数和结果的顺序，再运行验证。

在 **嵌套循环** 中，外层每次选一排，内层逐块补 3 格。每补完一排就记下结果，再换下一排。换成长短不同的电池排后，先猜共补几次和每排的结果，再运行验证。

在 **模块** 中，跟着 `main.py` 和 `algorithms.py` 看函数在哪里定义、什么时候导入，以及电量怎样在调用时传给参数。补电结果返回主程序后，换一个起始电量，先预测再运行验证。

在 **调试** 中，先补一块电池，再换一排，对照预期和实际结果。逐步找出循环里的 `return`，把它移到循环外，用原来那排重跑，再换一排预测和验证。

## 写程序过关

点击指令卡，用参数菜单选方向、数字或表达式。在 **我的程序** 勾选一条指令，再点指令卡，默认会加在所选指令后面。也可以切换到 **在前面添加**。连续添加的卡片按点击顺序排列，绿线标出下一张卡的位置。选中循环或条件块时，新卡和它同级。点 **向代码块添加指令** 可以把卡加进块内。

勾选多条指令，可以一起上移、下移或删除，并实时查看生成的 Python。勾选循环或条件块会带上其中的全部指令，误删后可点 **撤销删除**。切换到 **Python** 即可手写代码。运行后会逐步播放指令，错误会显示对应的代码行和简短提示。

代码编辑框显示行号。按 `Tab` 缩进，`Shift+Tab` 回退一级，回车会保留当前缩进，在以冒号结尾的行后自动多缩进一级。`Ctrl+Enter`（Mac 上是 `⌘+Enter`）直接运行。用键盘离开编辑框时，先按 `Esc` 再按 `Tab`。

棋盘下方的 **本图目标** 列出这张地图要完成的每一项，例如拾取全部目标物品、依次提交结果、停在出口。回放到哪一步，清单就勾到哪一步，拾取和提交会显示完成的数量。

在挑战场，标题下方的 **任务简报** 把说明拆成一句目标和逐条规则，并列出难度、回合上限、对手数量和地图或用例的数量。点 **固定简报** 后，滚动页面时简报留在顶部；点 **收起** 可以只保留这一行。算法挑战的 **验证用例** 按参数名显示每组输入和预期返回，运行后每个用例会标出通过或未通过，选中的用例显示实际返回值，**全部用例一览** 用一张表对照所有结果。任务列表按挑战类型分组并标出难度。点列表标题旁的按钮可以收起整栏，给棋盘和代码更宽的空间，这个选择保存在当前浏览器。

教学运行器支持变量、数字、字符串、`True` / `False` / `None`、列表和字典、索引、赋值、算术、比较、`and` / `or` / `not`、`if` / `elif` / `else`、`for` / `while`、函数定义与返回值，以及 `range`、`len`、`str`、`bool` 和 `pass`。用列表的 `append` 和 `pop()` 模拟栈，用 `append` 和 `pop(0)` 模拟队列。运行器在浏览器内执行课程代码，并限制程序步数和输出。

| 指令 | 行为 |
| --- | --- |
| `move("right")` | 向 `up`、`down`、`left` 或 `right` 走一格。碰墙或碰到敌人会停下来。 |
| `scan()` | 读取关卡提供的一份新数据。未配置数据时，返回角色四周的地形和物品情况。 |
| `pick()` | 拾取当前格子的一件物品并返回它的 ID。移动和拾取会推进一回合。 |
| `say("你好")` | 在运行反馈里显示文字。 |
| `submit(value)` | 按目标要求提交一个结果。某些关卡会检查结果是否来自指定的数据结构操作。 |
| `load(address)` / `store(address, value)` | 读取或写入从 0 编号的内存格。内存保存整数。 |
| `step()` | 执行一条 CPU 指令并推进一回合。支持 `LOAD`、`ADD`、`STORE` 和 `HALT`。 |

每关的 `allowedApi` 决定可用的游戏指令。带有 `variants` 的网格和从容对抗关卡会在不同输入或地图上检验同一份代码。棋盘上方可以切换地图，运行后也可以查看各张已执行地图的结果。紧张对局在主地图上进行，也可以暂停查看其他地图的初始布局。

有巡逻机器人、定时机关、多张地图或对手时，可以直接点 **观察地图**。芽芽留在起点，其他角色和通道按关卡规则变化。静态地图会逐张展示。可以暂停、逐步观察或重播，结束后接着编程。观察不会计入成绩或错题。

在 **黄铜钥匙仓**，踩到钥匙就会解锁对应的门，站到宝箱上用 `pick()` 开箱。**拐弯的光廊** 用镜子改变激光方向，踩下开关可以关闭相连的光源。**脉冲炮横道** 和 **倒计时货道** 要算好通过的时机，可以用 `wait()` 原地等一回合。关卡作者可在地图及其变体的 `devices` 数组里配置这些机关。

## 路径练习与竞技场

在算法练习里编写 `shortest_step(board, start, goal)`，让它返回最短路径上的第一步。棋盘行用 `.` 和 `#` 表示地板和墙，坐标是 `[x, y]`。输入检查通过后可以把函数保存到当前浏览器，在竞技场里用 `from my_algorithms import shortest_step` 调用。`from algorithms import shortest_step` 可以使用内置示范函数。

在 **算法进阶 → 广度优先搜索 → 设计整条最短路线** 中，用指令片段或 Python 编写 `plan_route(tiles, start, goal)`，返回从起点到终点的一列方向。终点不可达或起点已经是终点时返回空列表。通过六张测试地图后，把函数存入个人函数库。进入挑战场的 **三仓导航派送**，用「装入我保存的导航函数」指令卡或 `from my_algorithms import plan_route` 调用它。三张仓库地图共用同一份程序。`read_map()` 返回当前格子、芽芽位置和出口，关闭的门和固定障碍会标成墙。读取地图不占回合。

竞技场配置地图、零件、对手和回合上限。一场比赛与两个固定路线的机器人争夺零件，另一场要躲开两个追踪机器人和一个巡逻机器人，带着指定零件抵达出口。

- **从容模式** 可以逐行调用动作，也可以把编辑框的内容换成一个 `def decide(state)` 策略，每回合返回一个动作。点「运行」会检查主地图和变体，点「单步执行」可以逐步看双方怎么行动。
- **紧张模式** 在地图 1 上每 1.8 秒推进一回合。正式挑战在新局写好 `def decide(state)`，点「开始」即可运行当前策略。它每回合根据棋盘返回一个动作，如 `"right"`、`"pick"` 或 `"wait"`。键盘和按钮可用于手动试打。如果中途接管了动作，可以在练习结束后点「用 Python 从头挑战」，从第 1 回合开始计算正式成绩。

在 **挑战场 → 自由选关 → 机器人对抗**，选 **对抗目标 → 射击清场** 可找到全部脉冲淘汰赛。新增的 12 关从「铜铃开场赛」的一对一延伸到「花灯巡游总决赛」的一对四。芽芽要在回合上限内让全部对手停机，同时保住自己的耐久。可以抢强化芯片或护盾，也可以利用按回合开合的通道。「风琴排管赛」和「花灯巡游总决赛」还有一次性闸门开关。站在开关上按 **E** 或调用 `pick()`，本回合结束时对应闸门就会打开。对手也能抢先按下开关。

**机器人对抗** 的大地图有多种胜利条件。「霓虹弹球杯」要击退全场对手，「浪尖栈桥冲刺」只要抵达终点，「风筝邮包争夺赛」则要抢齐指定邮包。在紧张模式里用鼠标选择发射方向或防御，策略函数可以返回 `"shoot-left"` 等方向动作或 `"guard"`。从容模式的 Python 用 `shoot("left")` 和 `guard()`。

在机器人对抗和挑战场的网格关里，棋盘上方的 **弹出控制台** 可以打开代码或指令卡，点 **收起控制台** 就能看全棋盘。工作区会记住这个选择。点旁边的 **全屏地图** 可以铺满屏幕，全屏时用底部操作栏切换控制台。

机器人对抗的地图上方有 **查看地图 / 控制芽芽** 两个按钮，焦点在地图上时也可按 **M** 切换。默认查看地图，用方向键逐格查看。全屏时可用 **W A S D** 平移、**+ / −** 缩放、**Home** 看全图。

在触屏上全屏玩 **直接推箱** 或 **机器人对抗** 时，顶部的 **触控** 可以单独切换。默认选中 **操作地图**，拖动棋盘可以平移视野。选择 **移动芽芽** 后，单指滑动可以走一格。推箱子时，点远处空地，芽芽会绕开墙和箱子沿最短路线走过去。点上下左右相邻的空格就走一步，点相邻的箱子或朝它滑动就推一格。途中可以点别处改道，也可以点芽芽停下。每一步都会计数，也可以逐步撤销。对抗赛从容模式会切入紧张练习，从暂停的对局回来时仍需先点 **继续对局**。

选 **控制芽芽** 后，可以用 **方向键或 WASD** 移动、**E** 拾取。脉冲对抗还可用 **Shift + 方向键** 发射、**G** 防守。从容模式下选「控制芽芽」会进入紧张练习。新局按下第一个动作键就开始计时，并在第 1 回合执行该动作，也可以点「开始」。从暂停或存档回来时，先点「继续对局」。对局中可以随时切回查看地图，比赛按原节奏继续。进入或退出全屏会保留当前选择，编辑代码时按键用于输入。

**小地图** 会标出芽芽、对手、当前目标和镜头可见范围。在小地图上点一格，主地图就会保持当前倍率移到那里。点 **回到芽芽**，镜头会对准她现在的位置。收起小地图后也能用这个按钮。

脉冲沿直线前进，墙可以当掩体。用 `pick()` 拾取增幅芯片，每层让脉冲多造成 1 点伤害。每层护盾芯片能抵消 1 点伤害，两种芯片各可叠至 3 层。主动防御会在本回合为每次命中减伤 1 点。对手也能拾取芯片、发射和防御。

## 本机数据与视觉实验

数据科学课程在本机运行 NumPy、Pandas 和 SQLite。计算机视觉课程用实际的 OpenCV 和 YOLOX-S 完成预处理与检测。照片与模型来源见 [实验说明](labs/README.md)。

在 `PATH` 中准备 64 位 Python 3.11、3.12 或 3.13。首次安装需要联网，下载固定版本的依赖和约 36 MB 的检测模型。安装后保留 `labs/.venv` 和 `labs/.cache` 即可离线运行实验。

```sh
npm run labs:setup
npm run dev
```

编程与 AI 模拟练习可直接使用 Node 服务。通过 `npm run test:labs` 检查本机实验，模型和图片来源见 [实验说明](labs/README.md)。

## 用 AI 或手工编写关卡

1. 将 [JSON Schema](level.schema.json) 和 [编写约定](AGENTS.md) 交给编写关卡的 AI，再给出最相近的示例。讲解可参考 [四种整理方法](levels/103-structures-notes.json)，演示可参考 [打开计算机的观察窗](levels/106-computer-replay.json)，鼠标练习可参考 [把路线装进口袋](levels/03-pocket-route.json)，AI 协作可参考 [AI 补给搭档](levels/11-ai-supply-box.json)。
2. 让 AI 生成符合 Schema 的 UTF-8 JSON，写入唯一的 `id`、所在的 `unit`、课程阶段 `stage`，并为面向玩家的文字提供 `zh` 和 `en`。网格用 `.` 表示地板、`#` 表示墙，坐标从左上角 `(0, 0)` 开始。网格练习用 `cards` 提供鼠标操作，并在 `solutionCards` 中写出能通过主场景和全部变体的解法。
3. 在项目目录验证草稿。`--json` 可把错误路径和结果交回给 AI 修订。

   ```sh
   npm run --silent levels:check -- path/to/draft.json --json
   ```

4. 在网页的 **关卡预览** 中拖入或选择文件，检查内容后点 **一键试玩**。要加入正式关卡，把这个文件放进 `levels/`，然后刷新任务列表。服务按 `order` 读取关卡。

`npm run levels:check` 校验整个关卡目录并执行参考解法，包括本机数据实验。未安装实验依赖时，可以加 `--structure-only` 只检查关卡配置。`npm test` 运行核心自动化测试。

## 给家长或教师的在线 AI 设置

AI 协作练习默认使用内置模拟，无需 API 密钥。关卡可以安排零次、一次或多次模拟错误。导入预览也可使用练习模拟。

如需在正式关卡使用在线 AI，将 [.env.example](.env.example) 复制为项目根目录的 `.env`，填写 `AI_API_BASE_URL`、`AI_API_MODEL`、`AI_API_KEY`，重启游戏后选择 **在线 AI**。服务支持兼容 Chat Completions 的 JSON 模式，会把 `/chat/completions` 补到接口地址后面。远程地址使用 HTTPS，本地回环地址可用 HTTP。

密钥保存在 Node 服务。在线模式会向配置的服务发送提示词、可用物品和上一轮清单。有预置草稿时，首轮会把草稿一起发给模型。请让孩子使用游戏里的虚构物品和任务信息来写提示词。
